# Dawkowanie podchlorynu – dezynfekcja odcinka sieci

Kalkulator dawkowania podchlorynu sodu przy dezynfekcji odcinka sieci wodociągowej przez hydrant.

**Strona:** https://tomaszowsiak-cloud.github.io/dezynfekcja-sieci/

- ustawienie pompki dozującej dla zadanego przepływu na hydrancie i dawki,
- tabela stężeń chloru 1–10 l/s,
- objętość odcinka, czas napełniania i płukania dla rur PE, PVC, stali i żeliwa.

Jeden plik `index.html` – działa też offline (można go zapisać na telefonie).
Narzędzie pomocnicze: wynik zawsze potwierdź pomiarem chloru.
